# Kill Reward Calculator

Calculadora web do premio por abate do Controle Ceres Confinamento.

Endereco principal: https://leotavares1533.github.io/kill-reward-calculator/
Publicar este projeto atualiza a calculadora independente; a pasta `premio/` do projeto `financial-performance-tracking` e uma publicacao separada.

## Uso

Abra o site, suba o relatorio do sistema em CSV ou XLSX e valide a memoria de calculo por titulo, lote, fazenda e data de abate. O botao **Gerar PDF** usa a impressao do navegador para salvar a evidencia.
